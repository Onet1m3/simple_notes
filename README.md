# SuperNote

Простой десктопный блокнот на Rust (eframe/egui). У каждой записи есть название,
значение, необязательная дополнительная информация и группа.

## Возможности

- Поиск: поле сверху фильтрует записи по названию, значению, доп. инфо и группе (без учёта регистра).
- Добавление записи: кнопка «➕ Добавить» открывает отдельное окно с полями «Название»,
  «Значение», необязательными «Доп. инфо» и «Группа». Сохранить — Enter или кнопка, отменить — Esc.
- Группы: запись попадает в группу, если в поле «Группа» указать её название. Можно ввести
  новое название или выбрать существующую группу кнопкой ▾. В списке группы показываются
  сворачиваемыми секциями (по алфавиту), записи без группы — в секции «Без группы» в конце.
  Группа исчезает сама, когда в ней не остаётся записей.
- Копирование в буфер обмена:
  - один клик по записи копирует название;
  - двойной клик копирует значение.
- Редактирование: кнопка ✏ открывает то же окно с данными записи.
- Удаление: кнопка 🗑.
- Записи сохраняются автоматически.
- Трей (Linux): приложение живёт в системном трее. Крестик окна сворачивает его в трей,
  клик по значку показывает или скрывает окно. В меню значка есть пункты «Открыть»,
  «Запускать при входе в систему» и «Выход».
- Повторный запуск не создаёт вторую копию, а открывает окно уже работающей.

## Требования

- Rust 1.95 или новее (ставится через [rustup](https://rustup.rs)):
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
- **Linux**: системные библиотеки для оконной системы и графики.
  - Debian/Ubuntu:
    ```bash
    sudo apt install build-essential pkg-config libxkbcommon-dev libwayland-dev \
        libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev
    ```
  - Fedora:
    ```bash
    sudo dnf install gcc pkg-config libxkbcommon-devel wayland-devel libxcb-devel
    ```
  - Также нужен драйвер видеокарты с поддержкой Vulkan или OpenGL.
- **Windows**: Visual Studio Build Tools (компонент «Desktop development with C++»).
- **macOS**: Xcode Command Line Tools (`xcode-select --install`).

## Запуск из исходников

```bash
cd SuperNote
cargo run --release
```

Первая сборка займёт несколько минут. Готовый бинарник появится в
`target/release/supernote` (на Windows — `target\release\supernote.exe`).
Его можно скопировать куда угодно и запускать напрямую.

## Установка на Ubuntu

1. Установите Rust и системные библиотеки (см. «Требования» выше).
2. Соберите и установите приложение скриптом:

   ```bash
   cd SuperNote
   ./install.sh
   ```

   Скрипт работает без sudo, всё ставится в домашний каталог:
   - бинарник — `~/.local/bin/supernote`;
   - ярлык в меню приложений — `~/.local/share/applications/supernote.desktop`;
   - иконка — `~/.local/share/icons/hicolor/scalable/apps/supernote.svg`;
   - автозапуск при входе — `~/.config/autostart/supernote.desktop`
     (приложение стартует свёрнутым в трей).

3. Запустите SuperNote из меню приложений или командой `supernote`
   (или просто перезайдите в систему — он запустится сам).

Варианты:

```bash
./install.sh --no-autostart   # установить без автозапуска
./install.sh --uninstall      # удалить (записи в notes.json сохраняются)
```

Автозапуск также включается и выключается пунктом «Запускать при входе в систему»
в меню значка в трее. Для обновления после изменений в коде просто запустите
`./install.sh` ещё раз.

### Значок в трее

В Ubuntu значки в трее показывает расширение GNOME «AppIndicator», оно включено
по умолчанию. Если значка нет:

```bash
sudo apt install gnome-shell-extension-appindicator
```

затем перезайдите в систему и включите расширение в приложении «Расширения».
Если трей недоступен, приложение работает как обычное окно: крестик его закрывает.

### Wayland

Приложение Wayland не может само скрыть своё окно, а это нужно для сворачивания в трей.
Поэтому под Wayland SuperNote автоматически работает через XWayland. На экранах
с дробным масштабированием текст может выглядеть чуть менее чётким.

## Где хранятся данные

Записи сохраняются в файл `notes.json`:

| ОС      | Путь                                                  |
|---------|-------------------------------------------------------|
| Linux   | `~/.local/share/supernote/notes.json`                 |
| macOS   | `~/Library/Application Support/supernote/notes.json`  |
| Windows | `%APPDATA%\supernote\notes.json`                      |

Для резервной копии достаточно скопировать этот файл.
